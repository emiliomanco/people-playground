# people-playground

Sandbox de física con ragdolls inspirado en People Playground, en un único archivo: `peopleplayground.html`.

## Cómo jugar

Descarga `peopleplayground.html` y ábrelo con Chrome, Edge o Firefox. Funciona sin conexión y también en el móvil.

## Controles por defecto

| Acción | Control |
| --- | --- |
| Agarrar y arrastrar | Clic izquierdo |
| Menú contextual | Clic derecho |
| Congelar en el aire lo que arrastras | Clic derecho mientras arrastras |
| Mover la cámara | Botón central, arrastrar con clic derecho o flechas |
| Zoom | Rueda |
| Girar | Q / E (o rueda mientras arrastras) |
| Activar (disparar, encender, detonar) | F (mantener para uso continuo) |
| Mostrar u ocultar los datos | S |
| Voltear / congelar / seguir con la cámara | R / G / H |
| Borrar | Supr o X |
| Deshacer / copiar / pegar / duplicar | Ctrl+Z / Ctrl+C / Ctrl+V / Ctrl+D |
| Pausa / cámara lenta | Espacio / T |
| Vista de extremidades | L |
| Herramientas | 1-0 |
| Catálogo | C o Tab |

Todas las teclas se pueden cambiar en **Ajustes → Teclas**.

## Notas

- La física usa [planck.js](https://github.com/piqnt/planck.js) (licencia MIT), incluido dentro del HTML.
- Todo el arte pixel y los sonidos se generan por código; no hay recursos externos.
