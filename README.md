# The Playground

Sandbox de física con ragdolls inspirado en People Playground, en un único archivo: `theplayground.html`.

## Cómo jugar

Descarga `theplayground.html` y ábrelo con Chrome, Edge o Firefox. Funciona sin conexión y también en el móvil.

## Controles por defecto

Son los mismos que los del juego original y se pueden cambiar en **Ajustes → Teclas**.

| Acción | Control |
| --- | --- |
| Agarrar y arrastrar | Clic izquierdo |
| Menú contextual | Clic derecho |
| Congelar en el aire lo que arrastras | Clic derecho mientras arrastras |
| Mover la cámara | Botón central, arrastrar con clic derecho o flechas |
| Zoom | Rueda |
| Girar | A / D (o rueda mientras arrastras) |
| Colocar mirando a la izquierda / derecha | Q / E |
| Activar (disparar, encender, detonar) | F (mantener para uso continuo) |
| Vista detalle (estado, pulso, sangre, temperatura, líquidos) | S |
| Borrar | Retroceso o Supr |
| Copiar / pegar (con sus uniones) | C / Z |
| Deshacer / duplicar | Ctrl+Z / Ctrl+D |
| Voltear | R |
| Pausa / cámara lenta | Espacio / G |
| Mostrar u ocultar la interfaz | Tab |
| Herramientas / poderes | Ctrl |
| Vista de extremidades | L |
| Seguir con la cámara / centrar | H / Inicio |
| Herramientas | 1-0 |

## Qué incluye

- Personas con salud por extremidad: dolor, sangre, huesos rotos, desmembramiento, consciencia, pulso, temperatura corporal y respiración (se ahogan bajo el agua).
- Más de 230 objetos: armas blancas y de fuego, accesorios para armas, explosivos, lanzadores, armas de energía, electrónica, biológico, química y líquidos, maquinaria, vehículos, iluminación y objetos.
- Electricidad con cable de cobre y señales con cable de activación (botones, interruptores, detectores, contadores, retardadores...).
- Temperatura: fuego, metal al rojo, congelación, calefactores y refrigerantes.
- Líquidos: matraces que vierten y recogen, jeringas que inyectan y extraen, mezclas.
- Agua y lava con flotación. Mapas: Explanada, Foso de pinchos, Plataformas, Arena cerrada, Vacío, Mar, Piscina, Foso de lava, Torre, Bloques y Escaleras.
- Entorno: temperatura ambiente, lluvia, nieve, niebla y tormenta eléctrica.
- Herramientas de unión (soldar, bisagras, resortes, cuerdas, cadenas, vendas...) y poderes (empujar, atraer, levantar, rayo, fuego, frío...).
- Guardar escenas y guardar construcciones como artefactos en el catálogo.

## Notas

- La física usa [planck.js](https://github.com/piqnt/planck.js) (licencia MIT), incluido dentro del HTML.
- Todo el arte pixel y los sonidos se generan por código; no hay recursos externos.
